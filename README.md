# Step 1: YW-Viewer
A utlity to open game files

# Planned Features
- Model Viewer
- Map Viewer
- Image Viewer
- Animated Image Viewer
- Font Viewer

# Build Requirements
- CMake
- Visual Studio 2022 (or Later)

# Build Steps
```bash
cmake -B build
cmake --build build --config Release # or Debug
```
