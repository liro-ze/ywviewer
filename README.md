# Step 1: YW-Viewer
A software to open game files

<img src="./.github/showcase.png">


# Planned Features
- Model Viewer
- Map Viewer
- Image Viewer
- Animated Image Viewer
- Font Viewer

# Build Requirements
- CMake
- C++ Compiler:
    - Windows: Visual Studio 2022 (or Later)
    - Linux/Other: Any should work

# Build Steps
```bash
cmake -B build
cmake --build build --config Release # or Debug
```
